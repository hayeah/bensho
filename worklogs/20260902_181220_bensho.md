# What was built

- The crate at the repo root: `Bench`, `Sample`, `Row` + `row!`, `Options` (CLI helper that leaves unknown args to the bench), `schedule` over splitmix64, `calibrate`, `Stopwatch`, `Record`/`Calibration`/`COLUMNS`, an RFC-4180 CSV writer. Zero dependencies, 0BSD.
- `examples/toy.rs`, the spec's worked example, run in release: `vec_sum`/`fold_sum` x `small`/`large`, 3 rounds, 300 ms budget. The large cells calibrated to `Budget` (batch 3,063 and 4,425), the small ones ran `Full` at 1,000,000; every row carries its position, seed and verdict.
- `py/`: a uv project per the copied `/python` skill. `Results` (load, census, cells, anomalies, round/position/predecessor drift, figure, dump), `bensho-report` (typer), `results_notebook.py` (percent format, jupytext + papermill via `Makefile.py`), tests beside the source. ruff, pyright (0 errors) and pytest (7/7) green through `pymake all`; the notebook task executed against the toy CSV.
- The `/python` skill from hayeah/dotfiles copied verbatim into `.claude/skills/python/` so agents in this repo follow the same conventions.

# Lifted from embedbench, and what changed

- Kept: the pilot that doubles as warm-up; the batch calibrated to a time budget and fixed before round 1; batching (time M, divide); rounds; every row carrying its actual op count; the per-subject min/median summary on stderr; splitmix64.
- Changed: the fixed subject order per round became a per-round Fisher-Yates permutation seeded by `seed ^ round`, with `position`/`cells`/`seed` on every row so the order is reconstructible. The `calibrated` flag the yudu analysis inferred from `lookups < max` is now an explicit `Calibration` column (`Full`/`Budget`/`Floor`); the floor case (a cell too slow even for `min_ops`) is named instead of silently clamped. The op closure returns a count and may report its own elapsed, which embedbench had no room for. Rows stream to the writer per cell (a killed run leaves a usable CSV). The `--only` filter, `--out`, `--seed`, `--budget-ms` and `--min-ops` flags are new.
- Dropped: parity checks (a bench's business), the compiled-in subjects, the `n` column (a user column now).
- The yudu pipeline had no notebook (only `.py` modules and rendered `plots/*.png`), so the notebook here is new, to the skill's convention.

# Generic versus bespoke

| Need of the netstack rewrite | Whose job | How bensho leaves room |
| --- | --- | --- |
| count packets per op, not bytes/1460 | bench | `Sample::ops(packets)`; harness divides by it |
| reuse buffers across ops and rounds | bench | closure captures state once; pilot runs on the same state |
| engine time separate from harness time | bench | `Stopwatch` accumulator into a `Row` column; `ops` on the row makes `engine_ns/ops` one pandas line; `Sample::timed` if the closure wants its own elapsed |
| packets/s for small writes, Gbit/s for bulk | bench + analysis | `bytes` and `kind` user columns; report derives the unit per kind |
| sweep N idle connections into separate lines | bench | one cell per (tier, kind, N); N in `mode` and as a numeric column |
| sweep active-flow position and socket count | bench | more cells |
| per-row user columns | bensho | `Row`, `row!`, header rules |
| warm-up, calibration, batching, rounds, shuffle, seed, positions, CSV, CLI | bensho | the crate |
| peak RSS | bench | a `Row` column; run-wide high-water only, bensho has no per-cell hook |
